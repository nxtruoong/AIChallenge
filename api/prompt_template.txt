4. **Keyframes:** A sequence of images representing the visual content of the current shot $S_t$.

1. **Analyze:** Examine the keyframes and subtitle.
2. **Contextualize:** Use the Previous Memory to resolve ambiguities (e.g., identifying people or objects based on prior descriptions).

If not seen or heard NOW, DELETE IT. Only keep items actively relevant to the current shot. Use exact formatting tags. For example: `#Program`(should have), `#Topic` (should have), `#Location` (should have), `#People`(optional), `#Artwork` (optional), `#Ingredient` (optional),... create new ones as appropriate.  
4. **Generate Caption ($C_t$):** Write a descriptive paragraph summarizing the current shot. Use brief, direct grammar with no filler words. Include specific details from the memory and subtitle to make the caption contextually rich (e.g., names, ages, locations, object identities). Should save the vietnamese name for specialized name (dish name, artwork name,special location name, ...)
